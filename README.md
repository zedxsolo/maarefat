# معرفات

مكتبة معرّفات شاملة للغة سولان — كل أنواع المعرّفات الشائعة في مكان واحد، بواجهة عربية.

```
استورد "معرفات"
اطبع(معرفات.uuid7())     // 01a18e61-1973-775c-a486-86b1fe7492e1
اطبع(معرفات.ulid())      // 01M67626BKTN8DZY6TEQ0EBB3F
اطبع(معرفات.nanoid(12))  // ZvqEcIhsQu-a
```

## التثبيت

```bash
solan add owner/معرفات
```

ثم `استورد "معرفات"`. (غيّر `owner` إلى اسم حسابك أو منظمتك حيث نشرت المكتبة.)

## أي معرّف أختار؟

| الحاجة | الأنسب |
|---|---|
| مفتاح أساسي في قاعدة بيانات (ترتيب زمني) | `uuid7()` أو `typeid("user")` |
| معرّف عشوائي بحت لا يكشف شيئاً | `uuid4()` |
| معرّف ثابت من اسم (نفس الاسم ← نفس المعرّف) | `uuid5(اسم, فضاء)` |
| معرّف قصير في رابط أو واجهة | `nanoid()` أو `short_uuid()` |
| رمز دعوة أو قسيمة يكتبه الإنسان | `رمز_مقروء()` (مع حرف تحقق) |
| رقم قصير مشفّر من مفتاح رقمي | `sqids()` (ليس تشفيراً) |
| معرّف يبدأ بحرف دائماً (HTML/CSS) | `cuid()` |
| توافق مع أنظمة موجودة | `ulid()` `ksuid()` `objectid()` `snowflake()` |

## UUID (RFC 9562)

| الدالة | الوصف |
|---|---|
| `uuid1(خيارات)` · `uuid6(خيارات)` | زمن + عقدة (v6 مرتّبة زمنياً) |
| `uuid2(نطاق, معرف_محلي)` | DCE Security |
| `uuid3(اسم, فضاء)` · `uuid5(اسم, فضاء)` | مبنية على اسم (MD5 / SHA-1) |
| `uuid4(خيارات)` | عشوائية |
| `uuid7(خيارات)` | زمن unix مرتّب + عشوائي (موصى بها)، ترتيب صارم حتى داخل نفس المللي ثانية |
| `uuid8(بيانات, خيارات)` · `uuid8_sha256(اسم, فضاء)` | مخصصة |
| `NIL` · `MAX` · `فضاءات` | الثوابت (الفضاءات: `dns` `url` `oid` `x500`) |
| `حلل_uuid` · `هل_uuid(نص, نسخة, صارم)` | التحليل والتحقق |
| `نسخة_uuid` · `متغير_uuid` · `زمن_معرف` | الإصدار والمتغير والزمن (v1 وv6 وv7) |
| `نسق_معرف(معرف, صيغة)` | صيغ العرض (منها `"مختصر"` و`"base58"` و`"base62"`) |
| `v1_الى_v6` · `v6_الى_v1` | التحويل بين الإصدارين |
| `v7_حد(مللي, "ادنى"/"اعلى")` | أصغر/أكبر UUIDv7 لزمن معين (لاستعلامات النطاق) |
| `قارن_معرفات` · `رتب_معرفات` | المقارنة والترتيب |
| `معرف` | صنف كائني: `معرف.من(نص)` وخصائص `.نسخة` `.متغير` `.urn` `.hex` `.زمن` وطرق `.نسق()` `.قارن()` `.يساوي()` |

الخيارات قاموس اختياري، منه: `"زمن"` (مللي ثانية) و`"عشوائي"` (مصدر عشوائية مخصص).

```
معرفات.uuid5("python.org", "dns")        // 886313e1-3b8a-5372-9b90-0c9aee199e5d
معرفات.uuid7({"زمن": 1700000000000})      // بزمن صريح
خل م = معرفات.معرف.من("886313e1-3b8a-5372-9b90-0c9aee199e5d")
اطبع(م.نسخة, م.متغير, م.urn)            // 5 rfc9562 urn:uuid:886313e1-...
```

## بقية الأنواع

| الدالة | الوصف |
|---|---|
| `ulid(خيارات)` | ULID: 26 حرفاً، مرتّب أبجدياً، ترتيب صارم داخل نفس المللي ثانية |
| `nanoid(طول, ابجدية, خيارات)` | أبجدية مخصصة بلا انحياز إحصائي. أبجديات جاهزة منها `"ارقام"` و`"مقروء"` و`"بلا_ملتبس"` و`"عربية"` و`"ارقام_هندية"` |
| `ksuid(خيارات)` | KSUID (Segment): 27 حرفاً base62 |
| `objectid(خيارات)` | ObjectId (MongoDB): 24 خانة hex |
| `snowflake(عقدة, خيارات)` | مولّد Snowflake، `.جديد()` يعيد نصاً عشرياً (64 بت لا تتسع في الرقم العشري المزدوج) |
| `typeid(بادئة)` | بادئة نوعية + UUIDv7 بصيغة base32: `user_01h455vb...` |
| `short_uuid(ابجدية)` | UUID مختصر (22 حرفاً بأبجدية فليكر58 افتراضياً) |
| `sqids(خيارات)` | أرقام صحيحة ↔ معرّف قصير (`.ترميز([1,2,3])` و`.فك(نص)`)، متوافق مع sqids.org |
| `cuid(طول)` | يبدأ بحرف دائماً، **على نمط** CUID2 (يستعمل SHA-256 فلا يطابق CUID2 الرسمية بايتاً ببايت) |
| `رمز_مقروء()` · `رمز_دعوة()` · `رمز_رقمي()` · `هل_رمز_صالح()` | رموز يكتبها الإنسان، بحرف تحقق Luhn mod N يكشف أخطاء الطباعة |

دوال كل نوع (التحليل والتحقق واستخراج الزمن) متاحة عبر `معرفات.وحدات["ulid"]` و`["ksuid"]` و`["objectid"]` و`["typeid"]` و`["snowflake"]` وغيرها.

## أدوات

| الدالة | الوصف |
|---|---|
| `افحص(نص)` | يتعرّف على نوع أي معرّف ويستخرج الزمن والتفاصيل |
| `احتمال_تصادم(بتات, عدد)` · `تقرير_تصادم(نوع, عدد)` · `كمية_آمنة(نوع, احتمال)` | حاسبة التصادم (مسألة أعياد الميلاد) |
| `دفعة(مولّد, عدد, فريد)` | دفعة معرّفات، فريدة افتراضياً |
| `مولد_بذرة(بذرة)` · `ضبط_المصدر(ف)` · `اعد_المصدر_الافتراضي()` | عشوائية حتمية للاختبارات |

## سطر الأوامر

```bash
solan رئيسي.سو v7 -ن 5
solan رئيسي.سو v5 python.org dns
solan رئيسي.سو افحص 01ARZ3NDEKTSV4RRFFQ69G5FAV
solan رئيسي.سو تصادم uuid4 1000000
```

## ملاحظات أمان

- العشوائية الافتراضية من مولّد نظام التشغيل الآمن (`تشفير.عشوائي_بايتات`). **`مولد_بذرة` للاختبار فقط** ولا يصلح لإنتاج معرّفات حقيقية.
- المعرّفات الزمنية (v1 وv6 وv7 وULID وKSUID وObjectId وSnowflake) تكشف وقت إنشائها. إن كان ذلك مشكلة فاستعمل `uuid4()` أو `nanoid()`.
- `sqids` ليس تشفيراً، فلا تعتمد عليه لإخفاء بيانات حساسة.
- المعرّف الصعب التخمين لا يغني عن التحقق من الصلاحيات.

## الاختبار
